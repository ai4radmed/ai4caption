SideCaption — 운영 화면

대기 중
⚠ Google Chrome 전용입니다. 이 브라우저에서는 시작할 수 없습니다 — Chrome 을 열고 https://ai4radmed.github.io/sidecaption/ 를 입력한 뒤, 주소창의 앱 설치로 설치해 쓰세요.
EN: 영어 인식→그대로 표시 · KO: 한국어 인식→영어 번역 표시. 청중 화면은 항상 영어만.

① 보조 스크린 보조 모니터·프로젝터가 따로 있을 때 — 좌/우 세로 띠

② 오버레이 발표 화면(PowerPoint) 위에 겹쳐 뜨는 자막 띠 — 상·하·좌·우, 항상 위

운영 로그 (원문 / 청중용 영어)
마이크: Web Speech API 는 장치를 고를 수 없고 OS 기본 입력장치를 씁니다 — 윈도우 소리 설정에서 기본 마이크를 지정하세요.
오버레이: Chrome 의 항상-위 창(PiP)으로 뜹니다. 선택한 가장자리 크기(상·하=폭 전체, 좌·우=높이 전체)로 요청하지만 창 위치는 브라우저가 정하므로, 처음 한 번 원하는 가장자리(상·하·좌·우)로 끌어다 놓으세요. PPT 는 슬라이드 쇼 대신 읽기용 보기/창 모드 권장.
보조 스크린 자막 창에서 F 또는 더블클릭 = 전체화면.
